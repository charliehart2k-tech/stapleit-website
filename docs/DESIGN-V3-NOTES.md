# Black Glass V3

This pass responds to the August 2026 visual review.

- Deep black glossy glass replaces grey/blue card washes.
- Navigation is larger, darker and more optically layered; Remote Support and The Staple Blog retain green/purple accents.
- Homepage hero/status panel uses CSS glass and a liquid reflection rather than a fragile hero WebGL target.
- liquidGL is constrained to one contained optical target per page because v2.0.1 uses a shared renderer/canvas.
- Hero/service/audit stages keep the liquid-wave poster underneath video so WebGL snapshots have a non-black fallback.
- Service colour is used at edges and highlights, not as broad panel fill.
