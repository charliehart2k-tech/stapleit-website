# Live staging commands

After `./Start-Staging.ps1`:
- `home` / `support`
- `liquid` or `liquidaudit` — audit-only liquidGL POC
- `liquidoff` — CSS-only comparison
- `liquiddebug` — audit POC plus runtime status overlay
- `install-liquid` — verify local liquidGL SHA-256
- `doctor` — run the full acceptance check
- `edit`, `paste`, `inject`, `apply`, `aliases`, `paths`, `status`, `backups`, `log`, `errors`, `restart`, `quit`
