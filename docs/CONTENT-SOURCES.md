# Content sources

Public copy is rebuilt from these sources in this order:

1. Selected public-site snapshots under `reference/live-site/` and the approved
   public homepage references retained in `reference/`.
2. Explicit redesign/content instructions supplied during the project.

Confidential agreements are not content sources and are not stored inside this
working tree. The original full-site scrape archive is also kept outside the
project because it is a one-time source artefact, not a build dependency.

Do not invent service claims to fill placeholder routes. The remaining pages are
rebuilt page by page from the retained public snapshots.
