# Content sources

Public copy is rebuilt from these sources in this order:

1. Selected public-site snapshots under `reference/live-site/` and the approved public Homepage references retained in `reference/`.
2. Explicit redesign/content instructions supplied during the project.

Confidential agreements are not public content sources and are not stored inside the working tree. The original full-site scrape archive is also kept outside the project because it is a one-time source artefact, not a build dependency.

The active site is deliberately limited to the Homepage and IT Support while the redesign proceeds page by page. Do not reintroduce placeholder routes simply to make the navigation look complete. Future routes are rebuilt from retained public snapshots only when that page enters review.
