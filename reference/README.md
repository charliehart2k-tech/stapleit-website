# Reference material

This folder contains only non-confidential working references that are useful while rebuilding the remaining Staple IT pages.

## Kept here
- `live-site/` — selected HTML/text snapshots from the previous public website.
- `approved-homepage-reference.html` and `original-homepage.html` — public design/content references.
- `LIQUIDGL-VENDOR.json` — pinned liquidGL provenance/integrity metadata.
- `SOURCE-DATA.json` and `live-site/SOURCE-INVENTORY.json` — source mapping metadata.
- `build-notes/` — non-confidential implementation notes.

## Deliberately not stored in this project
- The IT Master Service Agreement or any other confidential agreement.
- The original 32 MB full-site scrape archive.

Those source artefacts are one-time/private references and must live adjacent to this working tree if they are ever needed again. They must not be committed, zipped with the framework, or uploaded to production.

Production output is generated from `site/` only. Nothing in `reference/` is deployable.
